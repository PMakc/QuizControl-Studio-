# QuizControl Studio

Локальная платформа для создания и проведения интерактивных викторин с телефонами участников и общим экраном (проектором или телевизором).

**Текущая версия: 0.6.4** · Windows 10/11 · Python 3.11+

## Возможности

- Создание нескольких игр, раундов и вопросов.
- Индивидуальный и командный форматы; распределение участников по командам организатором.
- Разные типы вопросов, варианты ответа, правильные ответы, пояснения и таймер.
- Приём ответов с телефонов или проведение устного раунда с ручным начислением баллов.
- Главный экран для проектора и отдельная страница участника.
- QR-код и ссылка для подключения участников.
- Таблица лидеров, итоги раундов и общий счёт.
- Реакции участников на главном экране.
- Медиатека: изображения, аудио и видео; прикрепление файлов к вопросам.
- Полноэкранная трансляция изображений и видео, управление воспроизведением.
- Синхронизация состояния игры между админкой, главным экраном и телефонами.
- Локальная база SQLite; данные сохраняются между запусками.

## Быстрый запуск на Windows

1. Установите **Python 3.11 или новее** с сайта [python.org](https://www.python.org/downloads/windows/). Во время установки включите опцию **Add Python to PATH**.
2. Скачайте ZIP-архив проекта или клонируйте репозиторий.
3. Распакуйте проект в обычную папку, например `C:\QuizControl`.
4. Запустите `START.bat`.
5. При первом запуске скрипт создаст виртуальное окружение `.venv`, установит зависимости и запустит сервер.
6. Откройте админку: [http://127.0.0.1:8080/admin](http://127.0.0.1:8080/admin).
7. Пароль организатора автоматически создаётся при первом запуске и выводится в окне сервера. Сохраните его.

После входа доступны следующие страницы:

| Назначение | Адрес |
|---|---|
| Админка организатора | `http://127.0.0.1:8080/admin` |
| Главный экран / проектор | `http://127.0.0.1:8080/display` |
| Участники | `http://127.0.0.1:8080/join` |

Чтобы остановить сервер, вернитесь в окно `START.bat` и нажмите `Ctrl+C`.

## Подключение телефонов

Если телефоны и компьютер подключены к одной Wi-Fi сети, участники могут открыть адрес компьютера в локальной сети с окончанием `/join`. QR-код подключения отображается в интерфейсе.

Для подключения участников через интернет `START.bat` может автоматически запустить **Tuna CLI**, если он установлен и настроен. Tuna — необязательный внешний инструмент; без него QuizControl работает локально. Установка и авторизация Tuna выполняются отдельно по инструкции проекта Tuna.

> Не публикуйте ссылку на открытую игру и пароль организатора в общедоступных местах. Используйте публичный туннель только на время мероприятия и завершайте его после игры.

## Ручной запуск

Из папки проекта выполните в терминале Windows:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app:app --host 0.0.0.0 --port 8080
```

Затем откройте `http://127.0.0.1:8080/admin`.

## Данные и резервное копирование

При первом запуске приложение автоматически создаёт:

- `quizcontrol.db` — игры, вопросы, участники, ответы, результаты и настройки;
- `config.json` — секретный пароль организатора;
- файлы в `media/` — загруженные изображения, аудио и видео.

Эти данные **не входят в Git-репозиторий**. Они исключены в `.gitignore`, поскольку могут содержать персональные данные участников, секреты и авторские медиафайлы.

Для резервной копии остановите сервер и скопируйте `quizcontrol.db`, `config.json` и всю папку `media` в безопасное место. Не отправляйте эти файлы в публичный репозиторий.

Для переноса на другой компьютер скопируйте проект, установите зависимости через `START.bat`, а затем перенесите резервную копию базы, конфигурации и медиафайлов.
