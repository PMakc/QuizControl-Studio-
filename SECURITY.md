# Безопасность

QuizControl Studio изначально предназначен для локального запуска организатором мероприятия.

- Не добавляйте в Git `config.json`, `quizcontrol.db`, содержимое `media/`, пароли, токены и ссылки на активные публичные туннели.
- Пароль организатора генерируется автоматически при первом запуске и выводится в консоль сервера. Не публикуйте скриншоты консоли с паролем.
- Не используйте один и тот же пароль в других сервисах.
- Не оставляйте публичный туннель включённым после мероприятия.
- Перед публикацией проекта проверьте, что в истории Git нет секретов и пользовательских данных. Простое удаление файла в новом коммите не удаляет его из предыдущей истории.
- Не размещайте приложение в открытом интернете без отдельной проверки и усиления безопасности.

Если вы обнаружили уязвимость, не публикуйте рабочие пароли, персональные данные или эксплуатируемые подробности в открытом Issue. Сначала свяжитесь с владельцем репозитория через доступный приватный канал.
